# Math Visualizer

A Python project for visualizing mathematical equations.

## Current Goal

Build a 2D equation visualizer that can take a mathematical equation,
evaluate it numerically, and display the resulting graph.

## Tech Stack

- Python
- NumPy
- SymPy
- Matplotlib

## Planned Features

- 2D function plotting
- User-defined equations
- Multiple equations on one graph
- Adjustable graph ranges
- Mathematical parameter visualization

## Future

A separate project will explore how mathematical visualization
connects to machine learning concepts such as functions,
parameters, loss, and optimization.
